# 配布キット（plicy / ふりーむ! / SNS 用）

itch.io と GitHub Pages 以外の配布先へ出すときの手順・素材・文案をまとめたもの。
**アップロード作業と投稿は作者（MUKKII）が行う**（各サイトのアカウントが必要なため）。
ここにあるのは「そのまま貼れる材料」一式。

---

## 1. 配布用パッケージの作り方

```bash
npm run build
cd dist && zip -r ../galaxtris-html5.zip . -x '.*'
```

できるもの：**約 1.3MB / 18ファイル / index.html がZIPの直下**。

### 移植性について（検証済み）

`vite.config.ts` の `base: './'` により全アセットが相対パス参照なので、
**どんな深さのURLに置いても、iframe に埋め込まれても動く**。
ヘッドレスChromiumで以下を実測して確認済み（`test/hostcheck.mjs`）：

| 条件 | 結果 |
|---|---|
| `/games/play/998877/` のような深いサブパス（PC） | 起動OK・404ゼロ・エラーゼロ |
| iframe 埋め込み（plicy 方式） | 起動OK・404ゼロ・エラーゼロ |
| iframe 埋め込み × iPhone | 起動OK・404ゼロ・エラーゼロ |

つまり **ZIPを上げるだけでよく、コードの変更は不要**。

### 想定内で出る404（放置してよい）

- `version.json` … itch.io のキャッシュ対策用。無いホストでは静かに無視される
- `audio/stage_bgm.mp3` … あればBGMに使う任意ファイル。無ければ内蔵の合成BGMで鳴る

どちらもコンソールに404が出るだけで、プレイヤーには何も表示されない。

### 外部依存はフォント1つだけ

`index.html` が Google Fonts の `DotGothic16` を読む。
**取得できなくてもフォールバック（Courier New / monospace）で普通に遊べる**。
外部リクエストを嫌うホストなら、フォントをZIPに同梱して `@font-face` に
差し替えてもよい（必須ではない）。

## 2. 配布先ごとのメモ

### plicy（https://plicy.net）
- 日本語の個人ゲーム投稿サイト。HTML5ゲームはZIPアップロード、**index.html がZIP直下**が条件。
- ゲームは iframe で配信される → 上記のとおり検証済みで問題なし。
- **アップロード容量の上限は必ず現地の投稿ページで確認すること**（本ZIPは1.3MBなので、
  よほど厳しくない限り通る想定）。
- スマホからのプレイが多いサイトなので、説明文の操作方法は**スマホを先に**書く。

### ふりーむ!（https://www.freem.ne.jp）
- 同じくZIP配布。審査があるので公開までに数日かかることがある。

### unityroom
- Unity専用なので**対象外**。

### ゲームアツマール
- サービス終了済み。出せない（念のため現状を確認のこと）。

### itch.io / GitHub Pages
- 既にCI（`publish-itch.yml` / `deploy.yml`）で自動公開済み。手作業は不要。

## 4. 紹介文（コピペ用）

### キャッチコピー（1行）

> ブロック合体パズル × 往年のレトロ全方向シューティング。
> 積んだテトリミノが、そのまま自機の砲門になる。

### 短い紹介（100字程度・投稿サイトの概要欄向け）

> 降ってくるテトリミノを自機にドッキングさせて機体を組み上げ、そのまま全方向シューティングへ。
> ブロックの開口部から極太ビームが出るので、「どう積むか」がそのまま「どう撃てるか」になります。
> 全10面。ブラウザですぐ遊べます。

### 長い紹介（配布ページ本文向け）

> **ギャラクトリス / Galaxtris**
>
> パズルタイムとシューティングタイムが交互にやってくる、80年代アーケード風のハイブリッドです。
>
> **パズルタイム** — 上から3つのブロックが同時に落ちてきます。自機や壁に触れた瞬間にドッキング確定。
> 機体がどんどん大きく、いびつになっていきます。いらないブロックは落として捨ててもOK。
>
> **シューティングタイム** — 組み上がった機体で全方向に自由移動。弾は**ブロックの開口部から**出ます。
> 出口が別のブロックで塞がっていると不発。だから「強い形」を考えて積むことがそのまま火力になります。
> 被弾したパーツは壊れ、切り離されたパーツは浮遊するので、拾い直すこともできます。
>
> 全10面。難易度は EASY / NORMAL / HARD、ステージセレクトもあります。
>
> **操作**
> - スマホ：画面を指でなぞるだけ（移動＋ショット）。移動はマウスと同じ相対操作で、指を動かした分だけ動きます。
>   落ちてくるテトリミノは**直接タップ**で回転。
> - PC：WASD / 矢印キー / テンキー（4826・7913）で移動、Space または Enter でショット。
>   1・2・3 または Tab で操作ブロック切替。Esc でポーズ、M で音声切替、F でフル画面。
>
> 作者：MUKKII

## 5. SNS 投稿文案

`<URL>` を配布先のURLに差し替えて使う。画像は **シューティング中 + ボス戦** の2枚が目を引く。

>

### 投稿のコツ

- **画像は必ず付ける。** 動きのあるゲームなので、可能なら実プレイの短い動画（10〜20秒）が
  静止画より圧倒的に伸びる。スマホでプレイしながら画面収録するのが一番早い。
- URLを本文に入れるとリーチが落ちる場合があるので、**URLをリプライにぶら下げる**手もある。
- 最初の1行で「何のゲームか」を言い切る。「テトリミノを積むと、その形のまま弾が出る」が一番強い。

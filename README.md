# 👾 テトリシュー (TETRISHOOT)

**「テトリス」のブロック構築 × 「ギャラガ」のレトロ縦スクロールシューティング** を融合させたブラウザゲーム！

🎮 **今すぐブラウザでプレイ**:  
👉 **[https://mukkii-game.github.io/tetrishoot/](https://mukkii-game.github.io/tetrishoot/)**

---

## 🕹️ ゲームのルール

1面 ＝ **テトリスタイム 15秒** ＋ **シューティングタイム 15秒**（計30秒）。  
全10面を生き残ればゲームクリア！

### 1. テトリスタイム（15秒）
- 上からテトリミノが降ってくる！
- 自機（初期は正方形のOミノ）を動かして、落ちてくるミノに触れると**ドッキングして自機が合体・巨大化**！
- 画面左右の壁にミノをくっつけると**「防壁」として固定化**され、敵や敵弾を防ぐ盾になります。
- 床に落ちたミノは粉砕消滅します。

### 2. シューティングタイム（15秒）
- 組み上がった機体でギャラガ風エイリアン編隊を迎撃！
- **ブロックと同じ太さの豪快な極太ビーム弾**を斉射！
  - `Oミノ`: 0門（弾は出ないが頑丈な肉壁）
  - `Tミノ`: **3門（広角3WAYビーム）**
  - `その他 (I, J, L, S, Z)`: **2門（ツインビーム）**
- **被弾判定**: 敵弾が当たった**特定のミノパーツにダメージ（耐久度2）**が入り、耐久が尽きると粉砕・脱落。自機の全パーツが破壊されたらゲームオーバー！
- 敵や敵弾は左右の壁や防壁ミノに当たると跳ね返り、進路を変更・消滅します。

## 🎮 操作方法

- **自機移動**: `[←]` `[→]` または `[A]` `[D]` キー / **マウス移動**
- **ショット**: `[Space]` または **マウスクリック**（自動連射あり）
- **ミュート切替**: `[M]` キー
- **リトライ**: ゲームオーバー/クリア時に `[Space]` または クリック

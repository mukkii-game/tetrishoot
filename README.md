## 🕹️ ゲームのルール

パズルタイムとシューティングタイムが交互に到来！  
全10面を生き残ればゲームクリア！

### 1. パズルタイム（3個同時降下）
- 上から3つのブロックが同時に降下！
- `[1][2][3]` や `[Tab]`、マウスクリックで操作するブロックを選択。
- 自機や左右の壁に触れた瞬間に**ドッキング確定して機体が合体・拡張**！
- 不要なブロックはスルー（床に落として粉砕）も可能。
- **3つのブロックを落とし終えたら即座にバトルへ突入！**

### 2. シューティングタイム
- 自機は **上下左右（WASD / 矢印キー、スマホは画面をなぞるポインティング移動）に全方向自由移動**！
- ブロックの**先端開口部（入口と出口）から極太ビーム弾を斉射**！
  - 弾の出る先が別のブロックで塞がれている場合は不発（露出部のみ発射）。
- 上空から宙返りダイブして襲来するエイリアン大編隊を迎撃せよ！
- 被弾したパーツは耐久度2で破壊。全パーツ破壊でゲームオーバー！

## 🎮 操作方法

### PC
- **移動**: `[WASD]` / `[↑][↓][←][→]` / **テンキー**（マウス移動では動きません）
  - テンキーは `4` `8` `2` `6` で上下左右、`7` `9` `1` `3` で斜め、`5` で停止
  - `4`+`8` のような同時押しでも斜めになります（矢印キーとの併用も可）
- **ショット / 回転**: `[Space]` / `[Enter]` または **マウスクリック**（自動連射あり）
  - 落下中のブロックパーツは、弾が当たった位置で回転方向が変わります（中央なら回らず真上へ反動）
- **操作ブロック切替**: 数字列の `[1]` `[2]` `[3]` または `[Tab]`（テンキーの1/2/3は移動に使用）
- **ポーズ**: `[Esc]` ／ **音声切替**: `[M]` ／ **フル画面**: `[F]`

### スマートフォン
- **移動＋ショット**: **画面を指でなぞる**（指一本。触れている間は撃ちっぱなし）
  - 移動は**マウスと同じ相対操作**。指を動かした分だけ自機が動きます（1:1）。
    画面のどこに触れてもよく、触れただけでは自機は動きません
- **ブロックパーツの回転**: **落ちてくるブロックパーツを直接タップ**
  （タップのたびに時計回りに1回転＋真上へノックバック。
  スマホでは弾でブロックパーツは回りません）
